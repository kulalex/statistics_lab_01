# Лабораторная работа № 1: свойства пьезоэлектриков и диэлектриков
**Выполнили:** 502842, 501924, 501195, 504720, 502388
У нас с друзьями есть проект по изучению ML-скрининга функциональных материалов типа магнетиков и пьезоэлектриков, соответственно отсюда родилась область данной ЛР

Проект содержит 2 датасета:
- 941 запись о максимальном пьезоэлектрическом коэффициенте;
- 4764 записи о показателе преломления

Объём на атом используется как структурный признак 1ого набора.

## Файлы

- `lab01_sprint1_piezo.ipynb` - ноутбук с выполненными расчётами, графиками и выводами
- `lab01_sprint1_piezo.html` - версия для чтения в браузере без кода
- `piezo_data.py` - загрузка, разбор формул и проверка данных
- `statlib.py` - статистические функции и графики
- `summary_metrics.csv`, `hypotheses.csv` - сводные результаты
- `data/` - два исходных файла без изменений
- `check_project.py` - проверки вычислений и целостности готового ноутбука
- `CHANGES.md` - перечень исправлений

## Запуск

Требуется Python 3.12. В отдельном окружении:

```sh
python -m pip install -r requirements.txt
jupyter notebook lab01_sprint1_piezo.ipynb
```

Для проверки готового проекта:
```sh
python check_project.py
```

## Как читать результаты

Меньший AIC означает преимущество относительно проверенных кандидатов, но не доказанное согласие с данными. GEV для показателя преломления остаётся проверенной рабочей гипотезой и отвергается тестом согласия. Итоговая таблица показывает как исходные p-value, так и поправку Холма. Имитации с подвыборками описывают имеющийся конечный набор, а не доказывают представительность базы для всех материалов.
